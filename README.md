# Telegram -> Bitrix24 Бот заказов матрасов

Автоматический сервис для распознавания заказов матрасов из Telegram-группы (на узбекском и русском языках) и мгновенного создания контактов и сделок в CRM **Битрикс24**.

---

## 🚀 Как это работает

1. Менеджер отправляет текст заказа в Telegram-группу (например, `#10x10x59 #lz20 ... Summa 1.580.000 ...`).
2. Бот перехватывает сообщение и производит интеллектуальный парсинг:
   - Хештеги заказа (`#10x10x59`, `#lz20`)
   - Телефоны клиента (автоматически нормализуются в `+998...`)
   - Модель/изделие (`Toper 10 sm`, `Mayami kaprz`)
   - Размер (`200/175`, `200/180`)
   - Ткань/чехол/боковины
   - Характеристики и наполнение (пружины, слои поролона, кокос)
   - Общая сумма (`Summa`)
   - Предоплата и способ оплаты (`Olindi 100.000 g karta` или `hammasi QR`)
   - Остаток к доплате (`Olasila`)
   - Адрес/район доставки (`Limanariya`, `Sergili`)
   - Дата доставки (`12.10.2026`)
3. Бот проверяет контакт в Битрикс24 по номеру телефона:
   - Если контакт уже есть в базе — привязывает его к сделке.
   - Если контакта нет — создаёт нового клиента.
4. Создаётся сделка в CRM со всеми полями, суммой, ожидаемой датой и подробным комментарием.
5. Бот **отвечает на сообщение в Telegram** со ссылкой на сделку и итоговой сводкой.

## 🛠 Настройка за 3 шага

### Шаг 1. Настройка Telegram бота

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и создайте бота командой `/newbot`.
2. Скопируйте полученный токен (например, `123456789:AA...`).
3. **ВАЖНО для работы в группах**:
   - В диалоге с @BotFather отправьте `/setprivacy`.
   - Выберите своего бота.
   - Нажмите **Disable**.
   - *(Либо просто сделайте бота администратором группы заказов).*
4. Добавьте созданного бота в группу, где менеджеры скидывают заказы.

---

### Шаг 2. Настройка Битрикс24

1. Перейдите в ваш Битрикс24:  
   **Разработчикам** -> **Другое** -> **Входящий вебхук**.
2. В правах доступа выберите: **CRM** (`crm`).
3. Скопируйте **URL входящего вебхука** (вид: `https://your-domain.bitrix24.ru/rest/1/abcdef12345/`).
4. *(Рекомендуется)* Создайте пользовательские поля для сделки в  
   **CRM** -> **Настройки** -> **Настройки форм и отчетов** -> **Пользовательские поля** -> **Сделка**:
   - `UF_CRM_TAGS` (Строка) — Теги заказа
   - `UF_CRM_MATTRESS_SIZE` (Строка) — Размер
   - `UF_CRM_MATERIAL` (Строка) — Ткань / чехол
   - `UF_CRM_MATTRESS_DETAILS` (Текст) — Наполнение / слои
   - `UF_CRM_PREPAYMENT` (Число) — Предоплата
   - `UF_CRM_PAYMENT_TYPE` (Строка) — Способ оплаты
   - `UF_CRM_BALANCE` (Число) — Остаток к оплате
   - `UF_CRM_DELIVERY_ADDR` (Строка) — Район/адрес доставки
   - `UF_CRM_DELIVERY_DATE` (Дата) — Дата доставки

> 💡 **Примечание:** Даже если вы пока не создали эти поля, скрипт автоматически запишет все данные в блок **«Комментарий»** сделки, поэтому ни одна деталь не потеряется!

---

### Шаг 3. Настройка файла конфигурации `.env`

Создайте или отредактируйте файл `.env`:

```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ
BITRIX_WEBHOOK_URL=https://your-domain.bitrix24.ru/rest/1/abcdef12345/

# Опционально: если хотите использовать Gemini AI для парсинга любого сленга:
GEMINI_API_KEY=
```

## 💻 Запуск

### Вариант 1: Запуск через Python напрямую

```bash
pip install -r requirements.txt
python bot.py
```

### Вариант 2: Запуск в Docker

```bash
docker compose up -d --build
```
